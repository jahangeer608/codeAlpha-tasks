# ✈️ Lingo Board

A language translation app that looks like it belongs at Gate 12.

No frameworks, no build step, no bloat — just HTML, CSS, and JS doing 
what they do best. Type or speak your text, pick a route (FROM → TO), 
and watch it land in the target language, boarding-pass style.

## Features
- 🌍 20 languages, instant translation
- 🎤 Voice input via Web Speech API
- 🔊 Text-to-speech playback
- 📋 One-tap copy
- 📱 Mobile-first, fully responsive
- ⚡ Zero dependencies — clone and open, that's it

## Quick start
Clone it, open `index.html`, start translating. Seriously, that's the 
whole setup.
